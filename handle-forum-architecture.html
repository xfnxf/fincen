Identity helpers

auth.js

Password hashing and verification use Node’s scrypt; token creation and constant-time comparisons support sessions and CSRF checks.

Password reset mail

mail.js

Uses nodemailer when SMTP_URL is configured. Without SMTP, reset messages go to the server log.

Opens node:sqlite, creates schema and indexes, and seeds the default forum categories.

Persistent store

SQLite tables cover users, sessions, forums, threads, posts, messages, notifications, feedback, reports, saved listings, and broker requests. The DB file is present locally but is not tracked in Git.
